# Hindsight Analytics

Local-first product analytics with a from-scratch DOM session recorder and replayer, autocaptured events, funnels, and feature flags — demoed on a bundled sample store.

## Features

- Session recorder / replayer without third-party capture libraries
- Autocaptured + custom events
- Funnel builder and basic product analytics surface
- Feature-flag panel
- Storage stays in the browser (IndexedDB)

## Stack

React 19 · Vite · TypeScript · Zustand · Tailwind · Vitest

## Run

```bash
npm install
npm run dev
npm test
npm run build
```
